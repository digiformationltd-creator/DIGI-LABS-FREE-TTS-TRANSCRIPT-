# Contributing to DIGI LABS

Thank you for your interest in contributing to **DIGI LABS**! We welcome bug reports, documentation improvements, UI enhancements, and feature requests.

## How Can I Contribute?

### 1. Reporting Bugs
- Check the [Issues tab](https://github.com/digiformationltd-creator/digi-labs/issues) to see if the problem has already been reported.
- If not, create a new issue describing the bug, your Windows OS version, and steps to reproduce.

### 2. Suggesting Enhancements & New Features
- We welcome feature suggestions! Please submit an issue labeled `enhancement` with details on the proposed workflow or voice capability.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a topic branch: `git checkout -b feature/my-new-feature`.
3. Test your changes locally (`npm start` or `npm run server`).
4. Commit your changes with clear, descriptive messages.
5. Push to your branch and submit a Pull Request targeting `main`.

## Development Setup

```bash
# Clone your fork
git clone https://github.com/your-username/digi-labs.git
cd digi-labs

# Install dependencies
npm install

# Launch Electron desktop interface
npm start
```

## Community Guidelines
Please be respectful and constructive in all discussions, pull requests, and issue threads.
