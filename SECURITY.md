# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The DIGI LABS maintainers take security seriously. If you discover a security vulnerability or exploit:

1. **Do not open a public issue.**
2. Send an email directly to **[info@digiformation.co.uk](mailto:info@digiformation.co.uk)** or message our official WhatsApp hotline at **+92 316 4467464**.
3. Include details of the vulnerability, affected components, and steps to reproduce.

We will acknowledge receipt within 24 hours and provide an update on remediation.

## Privacy & Local Processing Guarantee
- DIGI LABS processes scripts and generated audio locally on your PC.
- Google Gemini API calls connect directly to official Google endpoints using your private BYOK key with zero intermediate proxies.
